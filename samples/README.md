# Sample documents

Synthetic test fixtures — **no real patient data**. All names, IDs, ABHA
numbers and phone numbers are fabricated.

- `sample_cardiology_case.md` — a representative multi-section cardiology
  discharge summary (STEMI / primary PCI). Used to exercise the chunked
  long-document extraction pipeline (`backend/llm/extractor.py`).

Do not place real PHI here. Anything in this directory is committed to git.
